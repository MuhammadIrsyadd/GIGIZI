# 🥗 GIGIZI — *"Gizi di Ujung Jari"*

GIGIZI adalah platform kalkulator nutrisi yang dirancang khusus untuk masyarakat Indonesia. Dengan fokus pada bahan makanan lokal dan masakan sehari-hari (seperti menu Warteg), GIGIZI membantu siapa saja memahami apa yang masuk ke tubuh mereka dengan cara yang ramah, jujur, dan hangat.

## 👨‍💻 Sosok di Balik GIGIZI
Dibuat dengan 🥗 dan semangat hidup sehat oleh **Irsyad**.

## 💡 Asal Muasal: Kisah Anak Kos
GIGIZI lahir dari realita kehidupan seorang **anak kos**. Menghadapi tantangan dalam mengatur pola makan sehat di tengah keterbatasan pilihan dan budget, Irsyad menciptakan platform ini untuk membantu sesama anak kos (dan siapa pun) agar bisa memantau asupan gizi mereka dengan mudah. 

Aplikasi ini mengusung filosofi **"Dapur Digital"** — sebuah tempat yang hangat dan tidak kaku untuk merencanakan kesehatan masa depan.

---

## ✨ Fitur Utama
*   **🔢 Kalkulator Nutrisi Real-Time:** Hitung kalori, protein, lemak, karbohidrat, dan serat secara instan.
*   **🍲 Database Lokal Indonesia:** Dari Nasi Merah, Tempe Orek, hingga Usus Ayam dan Rendang.
*   **🖼️ Export Ringkasan (PNG):** Bagikan pencapaian gizi harian Anda ke media sosial dengan kartu yang cantik.
*   **💾 Simpan Menu:** Simpan piring digital favorit Anda ke dalam penyimpanan lokal.
*   **🤖 Tanya GIZI:** Asisten virtual cerdas yang siap menjawab pertanyaan dasar seputar nutrisi.
*   **🤝 Pilihan Komunitas:** Dapatkan inspirasi menu sehat dari pengguna lainnya.

## 🛠️ Tech Stack
*   **Framework:** [Next.js](https://nextjs.org/) (App Router)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **Animasi:** [Framer Motion](https://www.framer.com/motion/)
*   **Visualisasi:** [Recharts](https://recharts.org/)
*   **Search Engine:** [Fuse.js](https://www.fusejs.io/)
*   **Export Image:** [html2canvas](https://html2canvas.hertzen.com/)

## 🚀 Cara Menjalankan Secara Lokal

1. **Clone repository:**
   ```bash
   git clone https://github.com/MuhammadIrsyadd/GIGIZI.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Jalankan server pengembangan:**
   ```bash
   npm run dev
   ```
4. Buka [http://localhost:3000](http://localhost:3000) di browser Anda.
